# Universal Design Principles

This repo is the source of Bijan's global design principles. `install.sh` copies them into `~/.claude`, where every Claude Code session loads them.

- `bijan-design-principles.html`: the full guide.
- `global-CLAUDE.md`: the instructions installed as a block in `~/.claude/CLAUDE.md`.
- After editing either, run `./build-install.sh` to regenerate `install.sh`, and commit all three.
