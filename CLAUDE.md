# Universal Design Principles

This repo is the source of Bijan's design principles, shipped two ways:

- `dist/bijan-design-principles.zip`: a skill uploaded at claude.ai (Settings → Capabilities → Skills); reaches chat, Projects and cloud Claude Code sessions.
- `install.sh`: copies the guide into `~/.claude` and adds an always-on block to `~/.claude/CLAUDE.md` (run on a local machine).

Sources: `bijan-design-principles.html` (the full guide) and `working-terms.md`. After editing either, run `./build.sh` and commit the sources with both outputs.
